# 1QBit

> 1QB Information Technologies Inc. (1QBit) is a quantum computing software company founded in 2012 and headquartered in Vancouver, British Columbia, Canada. It builds hardware-agnostic algorithms and software for optimization, simulation, and machine learning that run across quantum, quantum-inspired, and classical high-performance computing hardware.

1QBit works in computational finance, life sciences and quantum chemistry, materials, and telecommunications, with hardware and platform partnerships including D-Wave, Fujitsu, IBM, and Microsoft Azure Quantum. It participates in DARPA's Quantum Benchmarking Initiative (QBI) on automated design tools for utility-scale quantum computation.

**API status (verified 2026-08-02): 1QBit publishes no public API.** Its 1Qloud marketing page cites Python SDK, gRPC, and REST API interfaces, but there is no public developer portal, no API reference, and no machine-readable contract (no OpenAPI, AsyncAPI, GraphQL SDL, MCP server, or A2A agent card was found on any reachable host). The former developer portal host `portal.1qbit.com` no longer resolves. Access to 1Qloud is arranged through industry partnership; the 1Qloud page's sign-up call to action points at Microsoft Azure Quantum.
